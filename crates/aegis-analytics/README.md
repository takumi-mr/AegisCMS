# aegis-analytics

プライバシー最優先の Cookie レス・アクセス解析エンジン（`feature = "analytics"`）。

## 概要

`aegis-analytics` は、GDPR や個人情報保護法に配慮し、ユーザーの追跡や Cookie を一切使わずにページビューやユニーク訪問者数を集計する軽量アクセス解析クレートです。

HTTP リクエストヘッダー（Do Not Track / Global Privacy Control）を厳格に尊重し、生の IP アドレスや User-Agent をデータベースに永続化しません。日次の統計データのみを集計・保存します。

## 主な責務・提供機能

- **プライバシー保護設計**:
  - **Cookie レス**: 端末に Cookie や localStorage 追跡トークンを一切保存しません。
  - **DNT / GPC の尊重**: ブラウザの `DNT: 1` または `Sec-GPC: 1` ヘッダーが有効な場合、解析データを破棄（集計対象外）。
  - **ソルト付き日替わりハッシュ**: 日次訪問者数は「当日限定の乱数ソルト + IP アドレス + User-Agent」のハッシュ値で当日中のみメモリ上で重複排除し、翌日にはソルトが破棄されるため過去に遡った照合は不可能です。
- **軽量ビーコン (`beacon_script`)**:
  - ページ読み込み時にわずか数行のインライン JavaScript ビーコンを配信。
  - 閲覧ページパスおよびリファラーホストのみを非同期送信。
- **効率的な集計とバッチ書き込み**:
  - アクセスログを 1 件ずつ DB に書かず、インメモリバッファで集計して定期的にまとめてデータベースへフラッシュ。
  - ページ別・日別・リファラー別・端末種別（デスクトップ / モバイル / タブレット / ボット）の統計を提供。
- **ボット判定 (`agent`)**:
  - 検索エンジンのクローラーや自動スキャンボットを識別し、実ユーザーのトラフィックと分離。

## モジュール構成

| モジュール | 説明 |
| :--- | :--- |
| `agent` | User-Agent 解析、端末種別判定、クローラー・ボット検出 |
| `config` | アクセス解析設定 (`AnalyticsConfig`) |
| `lib` | 集計サービスクラス、インメモリバッファ、ビーコンスクリプト配信 |
