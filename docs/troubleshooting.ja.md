# トラブル対応

まずログを見ます。Docker は `docker logs aegiscms`、systemd は `journalctl -u aegiscms` です。詳しさは環境変数 `RUST_LOG` で変わります（例: `RUST_LOG=debug`）。

## ログインできない

| 症状                                     | 原因と対処                                                                                                                                                                                                                                                                      |
| ---------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| ログに `No user accounts exist` と出る   | 新しいサイトにはアカウントがありません。`aegis-server user add admin --role admin` で作ります（[導入](install.ja.md#4-管理者を作成する)）。                                                                                                                                     |
| パスワードを何度か間違えて `429` になる  | 失敗が続くと、正しいパスワードでも 15 分間ログインできません。待つか、`aegis-server user unlock <ユーザー名>` で解除します。このコマンドは `[cache].backend = "redis"` のときだけ効きます。既定のメモリキャッシュでは、サーバーを再起動します（[認証](authentication.ja.md)）。 |
| パスワードを忘れた                       | AegisCMS を動かしているマシンで `aegis-server user passwd <ユーザー名>` を実行します。                                                                                                                                                                                          |
| プロキシの背後で全員が同時にロックされる | プロキシの IP が全員分として数えられています。`[audit].trust_forwarded_for = true` にします（[公開](publish.ja.md#2-自前のリバースプロキシ)）。                                                                                                                                 |

## サイトが開かない

| 症状                                         | 原因と対処                                                                                                                                                                                                          |
| -------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| サーバー上では開くが、別のマシンから開かない | バイナリは既定で `127.0.0.1` だけで待ち受けます。リバースプロキシを使うか、`[server].host` を設定します（Docker イメージは最初から全アドレスで待ち受けます。`-p 8080:8080` とファイアウォールを確認してください）。 |
| ポートがすでに使われている                   | 別のプログラムが 8080 を使っています。`--port 8081` で起動するか、`PORT` を設定します。                                                                                                                             |
| サブパスで Admin Studio が真っ白             | `[server].base_path` とプロキシの設定を合わせます（[設定リファレンス 4.2](configuration.ja.md#42-サブパスで公開する)）。                                                                                            |
| テーマやプラグインが反映されない             | インストールしたプラグインは、`[plugins].enabled` に書くまで無効です（ログに `is disabled` と出ます）。`[theme]` の名前の綴りも確認してください。                                                                   |

## アップロード、メール、アドレス

- **大きなファイルのアップロードに失敗する**: `[storage].max_upload_mb` と、プロキシの上限（nginx は `client_max_body_size`）を、同じ値かそれ以上にします。
- **フィードやサイトマップが `http://` になる**: プロキシから `X-Forwarded-Proto: https` を渡し、**設定 › SEO** で正規 URL を設定します。
- **メールが届かない**: `[notifications.email]` を確認し、`aegis-server notify test --to you@example.com` を実行します（[通知](notifications.ja.md)）。

## 起動・更新・復元

| メッセージ                                                                            | 原因と対処                                                                                                                                              |
| ------------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `The database has migration N applied, but this version of AegisCMS does not know it` | より新しいバージョンがこのデータベースを更新しています。そのバージョンを起動するか、古いほうを入れてバックアップを復元します（[更新](upgrade.ja.md)）。 |
| `Migration N was changed after it was applied (its checksum differs)`                 | リリース済みのマイグレーションファイルが書き換えられています。リリースの元のファイルを使ってください。                                                  |
| 復元時に `already exists (use overwrite option to replace)`                           | 復元先は一度起動したことがあります。空のフォルダかボリュームに復元するか、`--overwrite` を付けます（[復元](backup-restore.ja.md)）。                    |
| 復元時に `Warning:` の行が出る                                                        | 現在のスキーマにないカスタムフィールドが捨てられました。正しいスキーマを先に置いて、復元し直します。                                                    |

それでも分からないときは、バージョン（`aegis-server --version`）、動かし方、関係するログの行を添えて [issue を立てて](https://github.com/takumi-mr/AegisCMS/issues) ください。パスワードやトークンは先に消します。
