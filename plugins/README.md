# plugins/

**English** | [日本語](README.ja.md)

The directory for Wasm plugins bundled with your copy of AegisCMS (`[paths].bundled_plugins_dir` in the shipped configuration; plugins installed from Admin Studio go to `[paths].plugins_dir`, `data/plugins`). It is empty: no plugin is bundled with AegisCMS. Put the plugins you build yourself and want to ship with your copy or image here.

- One plugin = one directory (`plugins/<name>/`). Make `<name>` the same as the `name` in `plugin.manifest.json`.
- Placing a plugin here does not load it. It is enabled by turning it on in the Plugins screen of Admin Studio (no restart needed), or by adding its name to `[plugins].enabled` in the config file.
- You can check the installed plugins and whether they are enabled with `aegis-server plugin list`.

```text
plugins/
└── my-plugin/
    ├── plugin.manifest.json   # "name": "my-plugin"
    └── plugin.wasm
```

For how to build a plugin, see [docs/plugin_sdk_guide.md](../docs/plugin_sdk_guide.md); templates and samples are in [`sdk/`](../sdk). To build a block that can be placed in the body, the quickest start is [Creating your first block plugin](../docs/plugin_block_tutorial.md) (template: [`sdk/templates/rust-block`](../sdk/templates/rust-block)).

> [!NOTE]
> If you create a new Rust plugin inside this repository (`plugins/<name>/`), it is not part of the root `Cargo.toml` workspace, so `cargo build` fails with `current package believes it's in a workspace when it's not`. To bring it in as an official plugin, add it to the root `[workspace] members`. For a personal plugin, write an empty `[workspace]` at the end of the plugin's `Cargo.toml` to make it a standalone crate ([SDK guide 2.1](../docs/plugin_sdk_guide.md#21-preparing-the-template-and-generating-a-scaffold-task-pluginnew)).

## Official plugins

Since v0.13.0, every official plugin is installed from the [package store](../docs/store.md) (Admin Studio › Plugins › Store) instead of being bundled. Their source is in [AegisCMS-Plugin](https://github.com/takumi-mr/AegisCMS-Plugin). Code highlighting, Mermaid, PlantUML and the content blocks are listed as recommended.
